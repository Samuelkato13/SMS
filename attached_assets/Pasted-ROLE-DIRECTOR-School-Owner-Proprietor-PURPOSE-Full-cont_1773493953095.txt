ROLE: DIRECTOR (School Owner/Proprietor)
PURPOSE: Full control over ONE school - can do everything EXCEPT create another Director

DATABASE TABLES NEEDED:
- schools (id, name, address, phone, email, logo, motto)
- sections (id, school_id, name: Nursery/Primary/Secondary)
- classes (id, section_id, name: P.1/P.2/S.1/etc, numeric_level)
- streams (id, class_id, name: K/L/East/West)
- academic_years (id, school_id, name, start_date, end_date, is_active)
- terms (id, academic_year_id, name: I/II/III, start_date, end_date)
- subjects (id, school_id, subject_name, from_pool)
- class_subjects (id, class_id, subject_id, is_compulsory)
- staff (id, user_id, staff_number, department, phone)
- class_teachers (id, staff_id, stream_id, academic_year_id)
- subject_teachers (id, staff_id, class_subject_id, stream_id)
- grading_systems (id, section_id, name, grade_ranges JSON)

LOGIN PAGE:
- School-specific login
- Email/Password

AFTER LOGIN - DASHBOARD MUST SHOW:

TOP STATS CARDS:
1. Total Students (with +X new this term)
2. Total Staff (Teaching/Non-teaching)
3. Fee Collection (UGX and percentage)
4. Overall Pass Rate

SIDEBAR MENU (Only these items):
- Dashboard
- School Setup
- Staff Management
- Student Management
- Academic Setup
- Fees Management
- Reports
- Report Studio
- Financial Summary

SCHOOL SETUP PAGE:
- Edit school info (name, address, contacts, logo)
- Manage Academic Years (add/edit/activate)
- Manage Terms (dates per year)
- Manage Sections (Nursery/Primary/Secondary)
- Manage Classes (auto-suggest based on section)
  - Nursery: Baby, Middle, Top
  - Primary: P.1, P.2, P.3, P.4, P.5, P.6, P.7
  - Secondary: S.1, S.2, S.3, S.4, S.5, S.6
- Manage Streams per class
- Subject Pool (select from global or add custom)

STAFF MANAGEMENT PAGE:
- Staff list table: Name, Staff ID, Role, Department, Contact, Status
- Buttons: "Add Staff", "Edit", "Deactivate"
- Add Staff form: Personal details, Role selection, Department, Subjects (if teacher)
- CAN CREATE: Headteacher, Class Teacher, Subject Teacher, Bursar
- CANNOT CREATE: Another Director
- Staff can have multiple roles (e.g., Class Teacher + Subject Teacher)

STUDENT MANAGEMENT PAGE:
- Student list table: Adm No, Name, Class, Stream, Parent, Status
- Buttons: "Add Student", "Import CSV", "Export", "Archive", "Promote"
- Add Student form: Personal details, Parent/Guardian (min 2 contacts), Medical info, Photo
- Import: CSV/Excel with validation
- Archive: Soft delete with restore option
- Promotion Studio: Select students, choose new class/stream for next year
- Student ID generation (bulk print)

ACADEMIC SETUP:
- Configure Grading System per Section
  - Primary: Aggregate ranges (95-100=1, 85-94=2, etc.)
  - Secondary: Grade ranges (80-100=A*, 75-79=A, etc.)
  - Descriptors per grade
  - Remarks templates
- Exam Types: Opener, Mid-term, End-term, Test
- Create exams within terms

FEES MANAGEMENT:
- Fee structure per class
- Components: Tuition, PTA, Lunch, Transport, Development
- Payment plans (Full term, Installments)
- Discounts and scholarships
- Late payment penalties

REPORTS PAGE:
- School performance summary
- Class comparison charts
- Subject analysis
- Year-on-year trends
- Staff workload report
- Enrollment trends

REPORT STUDIO:
- Template designer per section
- Drag-and-drop elements: Logo, Photo, Details, Subjects table, Remarks, Signatures
- Preview before save
- Multiple templates per section

FINANCIAL SUMMARY:
- Revenue by term
- Collection rates
- Defaulters summary
- Payment method breakdown

RESTRICTIONS (CRITICAL):
- Director CAN create Headteacher, Class Teacher, Subject Teacher, Bursar
- Director CANNOT create another Director
- Director CAN delete any staff except self
- Director CAN view all data (students, staff, finances, academics)
- Director CANNOT be deleted by anyone else
