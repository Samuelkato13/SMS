ROLE: CLASS TEACHER
PURPOSE: Manage ONE specific class/stream

DATABASE TABLES NEEDED:
- Same as above plus class-specific views
- student_details (extended info)
- parent_communications (id, student_id, message, date, type)

LOGIN PAGE:
- School-specific login
- Email/Password

AFTER LOGIN - DASHBOARD MUST SHOW:

HEADER INFO:
- Class Name (e.g., P.2 K)
- Total Students: XX
- "Ms. Teacher Name" - Class Teacher

TOP STATS CARDS:
1. Total Students in my class
2. Boys / Girls count
3. Class Average
4. Top Student name

SIDEBAR MENU (Only these items):
- My Class Dashboard
- My Students
- Attendance
- Enter Marks
- Class Performance
- Report Cards
- Parent Communication

MY STUDENTS PAGE:
- Student table: Adm No, Name, Parent Contact, Current Average, Attendance %, Actions
- Search and filter
- CAN EDIT: Student name, Parent contacts, Address, Medical notes
- CANNOT ADD or DELETE students
- Action icons: Edit, View Profile, Print Report

ATTENDANCE PAGE:
- Today's date prominently displayed
- Student list with checkboxes: Present, Absent, Late
- Mark all present button
- Submit attendance button
- View attendance history
- Attendance statistics chart

ENTER MARKS PAGE:
- Select Subject (dropdown of subjects in this class)
- Select Exam (dropdown of available exams)
- Student list with marks input fields
- For PRIMARY: Marks (0-100) input
- For SECONDARY: U1, U2, U3, U4, MT, EOT inputs
- Auto-calculate totals and grades
- Save button (auto-save option)
- Validation: Cannot exceed max marks

CLASS PERFORMANCE PAGE:
- Subject performance charts
- Class ranking
- Top 10 students
- Bottom 5 students (for intervention)
- Performance trends over terms
- Export options

REPORT CARDS PAGE:
- Generate report cards for individual students
- Generate for whole class
- Preview before printing
- Add Class Teacher remarks
- Submit to Headteacher for approval

PARENT COMMUNICATION PAGE:
- Send messages to individual parents
- Broadcast to whole class
- Message templates
- Message history
- Read receipts

RESTRICTIONS (CRITICAL):
- Class Teacher CAN edit student personal details
- Class Teacher CANNOT add new students
- Class Teacher CANNOT delete students
- Class Teacher CAN enter marks for subjects they teach
- Class Teacher CAN view all subjects in their class
- Class Teacher CANNOT see financial data
- Class Teacher CANNOT access other classes
- Class Teacher CANNOT create users
- Class Teacher CAN generate report cards (draft only)
