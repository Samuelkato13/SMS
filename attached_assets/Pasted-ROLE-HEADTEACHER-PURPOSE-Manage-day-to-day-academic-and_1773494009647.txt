ROLE: HEADTEACHER
PURPOSE: Manage day-to-day academic and administrative operations

DATABASE TABLES NEEDED:
- Same as Director but with limited permissions
- exams (id, term_id, name, type, start_date, end_date, status)
- exam_schedules (id, exam_id, class_subject_id, date)
- student_attendance (id, student_id, date, status, remarks)
- marks (id, student_id, class_subject_id, exam_id, marks_obtained, grade, remarks)

LOGIN PAGE:
- School-specific login
- Email/Password

AFTER LOGIN - DASHBOARD MUST SHOW:

TOP STATS CARDS:
1. Total Classes
2. Total Teachers
3. Total Subjects
4. Exams This Term
5. Average Attendance

SIDEBAR MENU (Only these items):
- Dashboard
- Academic Calendar
- Teacher Management
- Students
- Exam Management
- Performance Reports
- Report Cards
- Print IDs

TEACHER MANAGEMENT PAGE:
- Teacher list table: Name, Staff ID, Role, Class/Subject, Status
- Buttons: "Add Teacher", "Assign Class Teacher", "Assign Subject Teacher"
- CAN CREATE: Class Teacher, Subject Teacher
- CANNOT CREATE: Director, Headteacher, Bursar
- Teacher assignment interface:
  - Select teacher
  - Select class
  - Assign as Class Teacher (only one per stream)
  - Assign subjects to teach

STUDENTS PAGE:
- Student list (view only + edit details)
- CAN edit: Name, Parent contacts, Address, Medical info
- CANNOT add new students (Director only)
- CANNOT delete students
- Search and filter by class/stream

EXAM MANAGEMENT:
- Create exams within terms
- Set exam dates
- Link subjects to exam
- Status: Draft, Published, In Progress, Closed
- Prevent marks entry after closure
- View marks entry progress per subject/class

PERFORMANCE REPORTS:
- Class performance ranking
- Subject performance trends
- Teacher effectiveness metrics
- Pass rates by class
- Student attendance summary
- Export to PDF/Excel

REPORT CARDS:
- View all report cards
- Verify marks before printing
- Approve final reports
- Print individual or bulk
- Email to parents
- Add Headteacher remarks and signature

PRINT IDS:
- Bulk student ID card generation
- Select class/stream
- Preview before print
- Lamination-ready format

ACADEMIC CALENDAR:
- View all exams, holidays, events
- Add school events
- Set important dates

RESTRICTIONS (CRITICAL):
- Headteacher CAN create Class Teachers and Subject Teachers
- Headteacher CANNOT create Directors, Headteachers, or Bursars
- Headteacher CAN edit student details
- Headteacher CANNOT add or delete students
- Headteacher CAN view all academic data
- Headteacher CANNOT access financial data (fees, payments)
- Headteacher CANNOT edit school settings (grading, fee structure)
