ROLE: SUPER ADMIN (SAAS Owner)
PURPOSE: Manage multiple schools across the platform

DATABASE TABLES NEEDED:
- tenants (id, school_name, subdomain, logo, status, created_at)
- users (id, tenant_id, email, password_hash, role, name)
- subscriptions (id, tenant_id, plan, start_date, end_date, status)
- audit_logs (id, user_id, action, details, ip_address, timestamp)

LOGIN PAGE:
- Email/Password fields
- "Login as Admin" button
- Forgot password link
- Remember me checkbox

AFTER LOGIN - DASHBOARD MUST SHOW:

TOP STATS CARDS:
1. Total Schools (with +X new this month)
2. Total Users across all schools
3. Monthly Revenue (UGX)
4. Active Subscriptions

SIDEBAR MENU (Only these items):
- Dashboard
- Schools Management
- All Users
- Subscriptions
- System Settings
- Audit Logs

SCHOOLS MANAGEMENT PAGE:
- Table with columns: School Name, Subdomain, Users Count, Status, Actions
- Buttons: "Add New School", "Edit", "Suspend", "Delete"
- Add School form: School Name, Subdomain, Email, Phone, Address, Logo upload
- Status: Active, Trial, Suspended, Expired

ALL USERS PAGE:
- Table showing all users across all schools
- Columns: Name, Email, School, Role, Last Login, Status
- Search by name/email/school
- Filter by role
- Can create Director or Headteacher accounts for any school

SUBSCRIPTIONS PAGE:
- Plans: Basic, Professional, Enterprise
- Features per plan
- Assign plan to school
- Payment history
- Invoice generation
- Expiration alerts

SYSTEM SETTINGS:
- Global subject pool (add/edit subjects)
- Email templates
- SMS gateway configuration
- Backup settings
- Security settings (password policy, 2FA)

AUDIT LOGS:
- View all system actions
- Filters: User, Action, Date Range, School
- Export to CSV/PDF
- Cannot delete logs

RESTRICTIONS (CRITICAL):
- Admin CAN create Director and Headteacher accounts
- Admin CANNOT create Class Teachers, Subject Teachers, or Bursars
- Admin CANNOT access individual student data
- Admin CANNOT view academic marks
- Admin CANNOT view payment details
- Admin CANNOT edit school-specific settings (grading, fees, etc.)

UI REQUIREMENTS:
- Clean, professional dashboard
- All tables must have pagination
- All actions must have confirmation dialogs
- Success/error notifications
- Loading states for all buttons
- Mobile responsive
