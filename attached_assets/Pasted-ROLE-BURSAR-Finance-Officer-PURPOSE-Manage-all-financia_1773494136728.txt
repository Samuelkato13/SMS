ROLE: BURSAR (Finance Officer)
PURPOSE: Manage all financial transactions and fees

DATABASE TABLES NEEDED:
- fee_structures (id, class_id, academic_year_id, term_id, amount, components JSON)
- payments (id, student_id, amount, payment_date, method, receipt_no, status)
- receipts (id, payment_id, receipt_number, generated_date)
- fee_balances (id, student_id, term_id, balance)
- transactions (id, date, description, amount, type, reference)
- bank_statements (id, bank_name, account_no, statement_date, closing_balance)

LOGIN PAGE:
- School-specific login
- Email/Password

AFTER LOGIN - DASHBOARD MUST SHOW:

TOP STATS CARDS:
1. Total Collected (UGX)
2. Outstanding Balance (UGX)
3. Today's Collections (UGX)
4. Collection Rate (percentage)

SIDEBAR MENU (Only these items):
- Dashboard
- Payments Received
- Fee Management
- Financial Reports
- Reconciliation
- Bank Statements
- Receipts

PAYMENTS RECEIVED PAGE:
- Recent payments table: Receipt No, Student Name, Class, Amount, Payment Method, Time
- Buttons: "Record New Payment", "Print Receipt", "Reverse Payment"
- Record payment form:
  - Search student by name/admission number
  - Select fee term
  - Enter amount
  - Payment method: Cash, Mobile Money, Bank Transfer, Cheque
  - Reference number (for mobile money/cheque)
  - Notes field
- Auto-generate receipt number
- Print receipt immediately

FEE MANAGEMENT PAGE:
- Fee structure by class table: Class, School Fees, PTA, Lunch, Transport, Total
- Buttons: "Edit Fees", "Add Fee Component", "Copy from Previous Term"
- Edit form: Fee components with amounts
- Payment plans per class
- Discounts section
- Scholarship management

FINANCIAL REPORTS PAGE:
- Daily collections report (with PDF export)
- Monthly revenue summary
- Term fee collection report
- Defaulters list with contact details
- Class-wise collection summary
- Payment method analysis
- Receipt journal
- Export all to Excel/PDF

RECONCILIATION PAGE:
- System balance vs Bank statement
- Upload bank statement
- Auto-reconcile feature
- Manual adjustment option
- Unreconciled transactions list
- Reconciliation history

BANK STATEMENTS PAGE:
- Upload bank statements
- View statement history
- Match with system records
- Download reconciled statements

RECEIPTS PAGE:
- Search receipts by number/date/student
- Reprint receipts
- Receipt cancellation (with reason)
- Daily receipt summary

STUDENT SEARCH:
- Find student by name/admission number
- View student fee balance
- Payment history per student
- Print statement of account

RESTRICTIONS (CRITICAL):
- Bursar CAN view student names and admission numbers ONLY
- Bursar CANNOT view student personal details (address, medical, parents)
- Bursar CANNOT view academic marks
- Bursar CANNOT edit school settings
- Bursar CANNOT create users
- Bursar CANNOT delete payments (only reverse with reason)
- Bursar CANNOT access staff management
- Bursar CANNOT view other schools' data
